# Deep Learning Computer Vision Projects

This repository showcases a series of computer vision projects implemented using PyTorch and Google Colab. Each notebook explores core topics in modern deep learning, ranging from image classification to generative models and 3D scene understanding.

## Projects

### 🖼️ `miniplaces_classification_with_nn.ipynb`
Built custom data loaders and implemented logistic, softmax, and fully-connected neural networks for classifying the MiniPlaces dataset.

### 🧠 `resnet_attention_and_custom_cnn.ipynb`
Developed CNNs and a ResNet-18 model from scratch. Visualized model attention with Class Activation Mapping (CAM) and experimented with custom architectures.

### 🔍 `vision_transformer_and_segmentation.ipynb`
Implemented a Vision Transformer (ViT) for image classification and extended it for semantic segmentation using the Oxford-IIIT Pet dataset.

### 🌫️ `diffusion_models_and_nerfs.ipynb`
Explored generative modeling with diffusion models and created 3D scene representations using Neural Radiance Fields (NeRFs).

## Tech Stack

- Python
- PyTorch
- Google Colab
- NumPy, Matplotlib, and torchvision
